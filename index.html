    BS.

    BrightSmile Dental

    Dental Practice Management System

    FULL-STACK APPLICATION Live · Frontend & Backend Deployed

    BrightSmile Dental is a live, fully connected dental practice management system built with Angular 21, TypeScript, ASP.NET Core 10 Web API, Entity Framework Core and Supabase PostgreSQL. The Angular frontend is hosted on Netlify and communicates with the Render-hosted API. Patients can register, manage profiles, book, reschedule and cancel appointments. Dentists manage assigned appointments; administrators manage dental services, dentists, patient records, reporting dashboards and CSV exports. Engineering highlights include JWT and role-based authorization, BCrypt password hashing, PostgreSQL transactions and dentist-scoped advisory locks for scheduling consistency, and OpenAPI documentation with Scalar. The repositories now include architecture diagrams, a database ERD, requirements, security, deployment and testing documentation. Automated tests and CI/CD quality gates remain planned improvements.

    Angular 21 Angular Material TypeScript C# ASP.NET Core 10 Entity Framework Core PostgreSQL JWT Docker Scalar / OpenAPI
    Frontend Repository ↗ Backend Repository ↗ View Case Study ↗ Live Demo ↗ Engineering Docs ↗ Scalar API Reference ↗ Architecture ↗

    SF.

    StockFlow

    Stock and Purchase Order Management System

    FULL-STACK APPLICATION In Development

    StockFlow helps a hardware store draft purchase orders. A buyer selects a supplier, adds products from that supplier’s catalogue and reviews the total in rand. Each order keeps the agreed prices when the catalogue changes. Approval, receiving and stock tracking are planned.

    Angular 22 TypeScript Java 21 target Spring Boot 4 Spring Security Spring Data JPA Hibernate PostgreSQL Flyway JUnit Vitest
    Frontend Repository ↗ Backend Repository ↗ Live Preview ↗ View Case Study ↗ Engineering Docs ↗ System Design ↗ Database ERD ↗ API Contract ↗
    Engineering Highlights
    Java Domain Modelling

    Draft creation validates quantities and catalogue offers, then saves the product name and supplier price for each line.

    PostgreSQL & Flyway

    Six Flyway migrations link suppliers, product offers and order lines in PostgreSQL.

    Automated Testing

    On 27 November 2026, 122 backend tests and 123 frontend tests passed locally. Maven packaged the API and Angular built the production bundle.

    Authentication & Architecture

    Spring Security enforces four employee roles. Administrators maintain supplier prices, and purchasing officers can create drafts through the Angular workspace.
