    BS.

    BrightSmile Dental

    Dental Practice Management System

    FULL-STACK APPLICATION Live · Frontend & Backend Deployed

    BrightSmile Dental is a live, fully connected dental practice management system built with Angular 21, TypeScript, ASP.NET Core 10 Web API, Entity Framework Core and Supabase PostgreSQL. The Angular frontend is hosted on Netlify and communicates with the Render-hosted API. Patients can register, manage profiles, book, reschedule and cancel appointments. Dentists manage assigned appointments; administrators manage dental services, dentists, patient records, reporting dashboards and CSV exports. Engineering highlights include JWT and role-based authorization, BCrypt password hashing, PostgreSQL transactions and dentist-scoped advisory locks for scheduling consistency, and OpenAPI documentation with Scalar. The repositories now include architecture diagrams, a database ERD, requirements, security, deployment and testing documentation. Automated tests and CI/CD quality gates remain planned improvements.
